# Plugins

_Switch workspace capabilities on and off._

**Plugins** add capabilities to a workspace. Enabling one can create the entities, forms and widgets it needs. Disabling it leaves your data alone.

| Plugin | Plan | What it adds |
|---|---|---|
| Contacts | Free | A Contacts entity (name, email, phone) with an internal form |
| Forms | Free | An Inquiries entity (name, email, message) with an internal form |
| Scheduling | Free | Appointments and a booking request |
| Invoicing | Premium | Invoices |
| Inventory | Premium | Bookable pools and allocations |
| Reports | Premium | Sales and usage reports |
| Automations | Premium | Trigger-to-action rules (planned) |
| Team & Roles | Premium | Roles and permissions |
| API Access / Webhooks | Enterprise | Developer API access and webhooks |
| White-labeling & SSO | Enterprise | Your branding and single sign-on |

How many plugins you can enable depends on your plan: Free allows 3, Premium and Enterprise are unlimited. A plugin above your plan can't be enabled and shows what upgrade it needs.

Plugins that create forms need an owner or manager.
